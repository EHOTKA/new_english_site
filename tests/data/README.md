# Тестовые данные (шаг 2)

Файлы `.srt` сюда **не коммитятся** — они генерируются из списка `FIXTURES` в
`make_fixtures.py`, потому что байты cp1252 и CRLF неудобно хранить в UTF-8
репозитории.

```bash
python tests/data/make_fixtures.py      # обновить вручную (pytest делает это сам)
```

| Файл | Кодировка | Перенос строки | Что проверяет |
| --- | --- | --- | --- |
| `basic_english.srt` | utf-8 | LF | чистый файл, точные таймкоды |
| `sdh_noise.srt` | utf-8 | LF | теги HTML/ASS, реплики `[MUSIC]`, `(CHUCKLES)`, ложные скобки |
| `sdh_full.srt` | utf-8 | LF | 26 реплик «настоящего» SDH: регрессионный эталон всей матрицы §4 |
| `speaker_labels.srt` | utf-8 | LF | `NAME:`, `OFFICER 1:`, `DR. SMITH:`, одиночный `COACH:` |
| `music_and_ellipsis.srt` | utf-8 | LF | `♪`, `#`, сохранение `...` и `#13-37` |
| `windows_cp1252.srt` | cp1252 | CRLF | legacy-кодировка + диакритика без «модзибаке» |
| `utf8_bom.srt` | utf-8-sig | CRLF | BOM не попадает в текст первой реплики |
| `no_index_numbers.srt` | utf-8 | LF | нумерация реплик необязательна |
| `malformed.srt` | utf-8 | LF | сломанный таймкод + перевёрнутый интервал (устойчивость) |
| `stress_realworld.srt` | utf-8 | LF | 90 cue стресс-корпус T6.1: вложенные и незакрытые HTML/ASS-теги, SDH-ремарки в `[]`/`()`, `♪ … ♪` и `# … #`, `>>>` и табы, литеральный `\N`, cue из одних символов |

Таймкоды **генерируемых** фикстур (кроме трёх, заданных блоками целиком: `sdh_full.srt`,
`malformed.srt`, `stress_realworld.srt`) строятся по правилу `start = 1000 + 1500·i мс`,
длительность 2500 мс, поэтому утверждения о конвертации в миллисекунды остаются стабильными.

Ожидаемые результаты (сколько реплик сохранено, сколько сброшено, какой текст)
живут в той же таблице `FIXTURES`, что и генератор: тесты импортируют её, поэтому
фикстура и ожидание не могут разойтись.
